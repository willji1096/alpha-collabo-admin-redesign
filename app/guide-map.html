알파콜라보 App — 시안 맵 & 가이드

전체 화면 30개의 구조와 흐름. 페르소나 김민지(클라이언트 마케팅 매니저) 기준으로 각 화면의 역할·진입 경로·핵심 기능을 정리. 이 페이지를 기준으로 개발 핸드오프와 화면 누락 점검을 진행.

3. 인플루언서

탐색 → 저장 → 채택 → 실시간 1:1 채팅. 외국인 인플루언서가 다수이므로 채팅은 자동 번역 필수.

인플루언서 탐색
phone/influencer-search.html
국가 · 채널 · 팔로워 범위 · 카테고리 필터로 검색. 카드 = 프로필 사진 + 핸들 + 평점 + 단가.
탭: 3번
저장한 인플루언서

찜한 명단. 다음 캠페인 대상 후보로 재활용.
인플루언서 상세
phone/influencer-detail.html
프로필 + 최근 콘텐츠 + 과거 캠페인 이력 + 평점. 채택 / 채팅 진입 버튼.
인플루언서 채팅NEW
phone/influencer-chat.html

패턴: 본문 = 번역, 작은 글 = 원문
