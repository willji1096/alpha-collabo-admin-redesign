# 알파콜라보 어드민 앱 — 작업 개념 & 페르소나

작성일: 2026-05-29 / 이 문서는 화면 판단의 기준점이다. 새 화면·요소를 더할지 뺄지 헷갈리면 여기로 돌아온다.

## 1. 한 줄 정의
이 앱은 **소비자 앱이 아니라, B2B 운영 콘솔(어드민)의 "모바일 동반자"** 다.
데스크탑 어드민에서 하던 캠페인 운영을, 클라이언트가 **자리에 없을 때 폰으로 이어서 처리**하기 위한 도구.

## 2. 무엇을 하는 서비스인가
알파콜라보 = 해외(글로벌) 인플루언서 체험단 마케팅 플랫폼.
서비스 플로우(클라이언트 기준):
**① 캠페인 등록 → ② 인플루언서 지원(10명 모집에 100명 지원) → ③ 채택/선정 → ④ 진행(방문·콘텐츠 제작) → ⑤ 검수/수정 → ⑥ 완료/정산**
이 앱은 ②~⑥의 "관리·의사결정" 국면을 폰에서 담당한다. (등록 ①은 PC에서 해도 됨)

## 3. 누가 쓰는가 — 페르소나

> **실사용 주체 (확정 2026-05-29): 클라이언트(광고주)가 "직접" 쓴다.**
> 알파콜라보 직원/매니저가 대행하는 구조가 아니다. 매니저는 카카오로 보조할 뿐.
> → 화면은 "마케팅 대행사 운영자"가 아니라 "광고주 본인(비전문 포함)"이 직접 보고 결정하는 눈높이로 설계한다.

### 페르소나 A — "이서진" (핵심)
- 32세, 중소 K-뷰티 브랜드 **마케팅 매니저**
- 일본·동남아 인플루언서 50명 모집 캠페인을 **동시에 여러 개** 운영
- 외근·출장·미팅이 많아 데스크탑 앞에 오래 못 앉아 있음
- 니즈: 지원자 폭주 후 **빠른 채택**, 올라온 콘텐츠 **즉시 검수**, 놓치면 안 되는 **알림 대응**

### 페르소나 B — "박상호" (보조)
- 45세, 성형외과 마케팅 실장 / 또는 맛집·소상공인 사장
- PC 어드민이 익숙지 않고 **폰 중심**. 세부 운영은 알파콜라보 **전담 매니저에게 의존**(카카오로 소통)
- 니즈: 복잡한 표 말고 **요점만**, 매니저가 보내준 것 확인·승인, 잔액·정산 체크

## 4. 어떤 상황에 — 사용 트리거
- 신규 지원자 **푸시 알림** → 바로 들어와 프로필 보고 채택
- 검수 요청/수정 데드라인 → 이동 중 콘텐츠 확인·승인
- 전담 매니저 메시지 → 응답
- 잔액 부족/정산 시점 → 충전·정산 확인

## 5. 왜 폰인가 (데스크탑으로 안 되는 이유)
캠페인은 **실시간성**이 핵심이다. 지원자는 빨리 채택해야 좋은 인플루언서를 놓치지 않고,
검수는 데드라인이 있다. 데스크탑 앞에 있을 때만 일하면 타이밍을 놓친다.
→ **푸시 알림 + 폰 즉시 대응**이 비즈니스 손실을 막는다.

## 6. 어떻게 (구조 = 하단 5탭)
- **홈** — 오늘 현황 요약·할 일·바로가기 (의사결정 진입점)
- **캠페인** — 상태별(신청~정산) 관리, 채택·검수
- **일정** — 방문/콘텐츠 스케줄, 캘린더
- **메시지** — 인플루언서·매니저 소통
- **더보기** — 잔액/요금/공지/가이드/로그아웃

## 7. 이 개념에서 나오는 디자인 원칙 (작업 기준)
1. **정보 무손실** — 운영 도구다. 원본 어드민의 필드/숫자를 모바일이라고 임의로 빼지 않는다. (가짜 데이터 대체 금지)
2. **의사결정 CTA 우선** — 채택/검수/승인처럼 "결정" 액션이 화면에서 가장 또렷해야 한다.
3. **알림·배지 중심** — 트리거가 알림에서 시작되므로 안 읽음/대기 상태 표시가 중요.
4. **라이트 단일 톤** — 다크 배경·넓은 accent 그라디언트 금지(전체 라이트). 실무 도구의 담백함.
5. **소비자 앱 톤 금지** — travel/medical/마케팅 랜딩 감성 아님. 빠르게 읽고 처리하는 B2B 콘솔.
6. **원본에 없는 임의 추가 경계** — 화면/요소를 새로 넣을 땐 "이게 실제 어드민 기능에 있나?"부터 확인 (예: 설정 톱니=근거 없어 제거, 매니저 채팅=카카오 가능성으로 보류).

## 7.5 핵심 정책 — 인플루언서 직접 소통 금지 (확정 2026-05-29)
**인플루언서는 알파콜라보의 자산(핵심 해자)이다.** 클라이언트(광고주)가 인플루언서와 직접 소통하면 다음엔 플랫폼을 건너뛰고 직접 계약하는 우회(디스인터미디에이션)가 일어난다. 그래서:
- 클라이언트↔인플루언서 **직접 소통 창구를 앱에 두지 않는다** (실시간 채팅·쪽지 모두).
- 모든 소통은 **알파콜라보 매니저가 중간 조율** (매니저↔클라이언트는 카카오).
- 클라이언트가 인플루언서에게 전달할 것(콘텐츠 수정요청·제안 등)은 자유 소통이 아니라 **캠페인/검수 화면의 구조화된 액션**으로 매니저에게 전달 (원본 modal-revision/modal-propose 패턴).

### 이 정책의 화면 파급 (결정)
- **influencer-chat 제거** (원본 웹에도 실시간 채팅 없었음. 메시지함 modal-message는 쪽지 수준이나 그것도 직접 소통이라 앱엔 미반영)
- **manager-chat 제거** (매니저 소통은 카카오)
- **메시지 탭(하단 4번째) 제거 → 알림으로 통합, 하단 4탭화** (홈/캠페인/일정/더보기)
- notification-center(알림)는 유지

## 8. 스코프 경계
- 우리 역할 = **디자인(HTML/CSS 시안)**. 개발·결제연동·기능구현은 개발팀.
- 계정 발급은 알파콜라보가 함 → 앱/어드민에 계정설정·프로필 페이지 만들지 않음.
