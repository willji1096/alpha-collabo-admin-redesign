# 브랜드사 어드민 — 부족한 점 감사 (Gap Audit)

> 2026-06 기준. 4개 영역 병렬 감사(신청서관리/탐색라인/대시보드·요금표·차감/전역UX) 결과 통합.
> 모든 항목 파일:라인 근거 기반. 우선순위대로 처리 권장. 기준: `docs/SERVICE-FLOW.md`.

## A. 최우선 (높음) — 구조·신뢰·핵심동선

### A1. 빈/로딩/에러 상태가 전 화면에서 죽어 있음 ★가장 큰 갭
- 13개 목록 페이지(list/selection/inspection/revision/completed/unselected/cancel-selected/influencer-search/saved/visit-planned/schedule-list/notice)의 **빈 상태가 HTML 주석으로만** 존재 → 0건이어도 아무것도 안 뜸. (list.html:239-252 등)
- **로딩 스켈레톤·에러 상태는 아예 0개** (design-system.html 데모 제외).
- balance-history는 empty-state 마크업조차 없음(유일).
- → 개선: 공통 empty/loading/error 패턴을 살아있는 형태로 최소 1세트 배포 + 표준화.

### A2. 차감현황(balance) 수치 붕괴 + 충전 흐름 부재
- 러시아 잔액이 한 페이지 안에서 **1,265,171(balance-history:244) ↔ 4,655,505(:699)** 충돌.
- 한국 잔액 **3,000,000(balance-history:376) ↔ drawer-balance:48의 2,847,320** 불일치.
- 헤더/Drawer "잔액 **1,284,500**"(header:59)이 본페이지 어디에도 없음(출처불명).
- **충전(입금) 내역 자체가 없음** → "충전−차감=잔액" 산식 성립 안 함. 총 잔여금액 요약도 없음.
- → 개선: 잔액 단일 산식 고정(전 국가 잔여 합), 충전 내역 탭 추가, 상단에 총 잔여 강조. (※수치는 매니저/실데이터 확인 필요)

### A3. 인플루언서 탐색·제안 라인 핵심 동선 죽음
- **visit-planned = influencer-search 복제본**(라인단위 동일). SERVICE-FLOW §5 "임박 영업 핫리스트" 의도 전무 — 방문일 정렬·임박 배지·제안 강조 없음. (visit-planned.html:91-418)
- visit-planned **리스트뷰 제안/저장 버튼에 핸들러 클래스 누락** → 제안 모달 안 열림(카드뷰만 동작). (visit-planned.html:150-417)
- **제안 모달이 행 데이터와 연결 안 됨** → 누구를 눌러도 하드코딩 "yuki_beauty"만 표시. (modal-propose.html:23-26, components.js:307-311; tr에 data-name/sub 없음)
- **보낸 제안 추적(상태) 화면 전무** → 능동영업의 후속관리 절반이 빈칸.
- → 개선: visit-planned 전용 임박순+배지+제안CTA, 행 dataset 부여, "보낸 제안" 목록 신설.

### A4. 신청목록 정보 위계 역전 (SERVICE-FLOW §7 위배)
- 주체여야 할 **인플루언서가 plain text로 약하고, 캠페인명(c-camp-name)이 굵게 최상위**. 아바타 없음, 컬럼 순서도 캠페인 우선. (list.html:120-140)
- → 개선: 인플루언서를 카드/행 주체로(아바타+핸들 강조), 캠페인은 보조 컨텍스트.

### A5. 데이터 정합 오류
- 검수 thead "전체 **10**건"인데 실제 `<tr>` **9개** (list-inspection.html:112 vs tbody).
- 완료 페이지 thead **`인플루언서` 컬럼 2개 중복** (list-completed.html:128,131).
- pipeline 건수와 일부 페이지 count 교차검증 필요.
- → 개선: 건수·컬럼 정합 수정.

## B. 중요 (중간) — 정책·동선·일관성

### B1. 직접소통 금지 정책 위반 소지 (SERVICE-FLOW §6)
- drawer-influencer가 **이메일·휴대폰(010-…) 직접 노출** (drawer-influencer.html:43-49) → 우회 직접연락 가능.
- 제안 모달·schedule "보내기"가 **"매니저 경유"임을 안 드러냄** → 브랜드사→인플루언서 직접 전송처럼 읽힘. (modal-propose.html, schedule-list.html:195)
- → 개선: 연락처 마스킹, 제안/발송 UI에 "매니저 통해 전달" 명시.

### B2. 흐름 단절 (단계 간 행-단위 이동 없음)
- 한 건 처리(선정/검수) 후 다음 단계의 그 건으로 가는 동선 없음 — 토스트만. 페이지 이동이 사이드바+단계바 의존.
- 이탈 3종(미선정/취소) 페이지엔 단계바도 없고 복귀/복원 동선 0.
- → 개선: 처리 후 "다음 단계로" 유도, 이탈 페이지에 되돌리기/맥락.

### B3. 대시보드 액션 유도 약함
- KPI 4종 **비링크**(클릭해도 목록 안 감), spark 차트 **더미 path**, "전체 보기" **href="#"**. (dashboard.html:101-177)
- "검수 임박 D-1 / 선정 대기" 같은 **SLA 처리유도 위젯 없음**.
- → 개선: KPI 딥링크, 처리필요 액션카드 추가, 더미 차트 정리.

### B4. 필터가 장식 (결과 미반영)
- 탐색/목록 필터 select·checkbox에 핸들러 없음, 검색은 toast만. chip 요약("국적 일본")이 실제 결과(RU/CN 혼재)와 불일치. (influencer-search.html:32,52-89)
- 국가/채널 필터가 토글 1개뿐(다국적인데 선택 UI 부재).
- → 개선: 시안이라도 chip-결과 정합 + 최소 1개 필터 동작 데모.

### B5. ⌘K(cmdk) 부분 장식 + 누락
- "새 캠페인 등록/엑셀/로그아웃" **3개 죽은 액션**(로그아웃이 cmdk에선 실제 로그아웃 안 됨). (components.js:1831-1836)
- 사이드바 대비 **7개 페이지 미등록**(방문예정·저장·차감·요금표 4종 등).
- → 개선: action 연결 + COMMANDS 누락 추가.

### B6. 요금표 6종 톤 불일치 + 단순 나열
- pricing/korea/it 일본 행 데이터 동일(차별점 불명), country-code 칩 패턴 불일치, 비용 가늠 예시/계산 전무. (pricing*.html)
- → 개선: 표별 차이 설명, 비용 계산 위젯, 칩/헤더 패턴 통일.

### B7. 공지(notice) 빈약
- 공지 1건(자기참조 더미), 읽음/중요/NEW 기본기 전무. (notice.html:117-123)
- → 개선: 실제같은 공지 3-5건 + 중요 고정 + 미열람 배지.

### B8. 내비 일관성
- balance-history `data-active-tab="계정"`인데 헤더에 "계정" 탭 없음 → 헤더 활성 0. (balance-history vs header.html)
- 활성 nav에 **aria-current 없음**(접근성).
- → 개선: 계정 영역 헤더 연결, aria-current="page" 부여.

## C. 정리 (낮음) — 룰·디테일

- **이모지 룰 위반**: login.html 비밀번호 토글(🙈 등 2건), cmdk 아이콘(📅📊📋… 6+건) → SVG/dingbat 대체.
- 검수 페이지 **bulk-bar 없음**(10건 최다인데 대량처리 불가), 행별 액션 노출 규칙 불명.
- balance-history **href="#" 21개**가 실제 SNS/리뷰 URL인데 무동작 → 실 URL + target=_blank.
- 채널 URL 더미에 `test`류 잔존(list.html 등) → 실제같은 핸들로.
- 팔로워 표기 한/영 혼용("1천~1만" vs "10~50k").
- 비가역 작업 toast에 undo 없음(현재 confirm으로만 방지).
