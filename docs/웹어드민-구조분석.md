# 웹 데스크탑 어드민 구조 분석 (원본)

분석일: 2026-05-30 / 대상: 루트 *.html 22화면 + components/

## 0. 한 줄 요약
이 어드민의 본질 = **"리뷰 캠페인 라이프사이클 관리 콘솔"**.
신청 → 선정 → 검수 → 수정 → 완료(+취소/미선정) 파이프라인을 단계별 테이블로 관리하고,
각 단계 전환 액션은 모달/드로어로 처리한다.

## 1. 네비게이션 (이중 구조)
- **헤더탭(대분류 5)**: 캠페인관리 / 신청서관리 / 인플루언서 탐색 / 사이트관리 / 요금표
- **사이드바(7그룹 22메뉴)** + ⌘K 검색 + 도구(관리메모·포인트계산기) + 유저프로필
- 헤더탭 `data-tab` ↔ 사이드바 `nav-group data-tab` 연동

## 2. 리뷰 파이프라인 (핵심 — list 계열 8화면)
컬럼만 다르고 구조 동일: `.tbl.has-sticky` + 체크박스 + 국가 sticky컬럼 + 정렬 + 3단 필터(active칩 + 접이식 고급필터 + density토글) + 엑셀다운

| 단계 | 화면 | 컬럼수 | Primary 액션 | 연결 모달/드로어 |
|---|---|---|---|---|
| 신청 | list | 12 | 리뷰어선정 | drawer-influencer, modal-address |
| 선정 | list-selection | 14 | 정보입력(배송) | +modal-shipping |
| 검수 | list-inspection | **17(최다)** | 리뷰검수 | modal-review, modal-revision, drawer-balance |
| 수정 | list-revision | 13 | 리뷰검수 | modal-review, modal-revision |
| 완료 | list-completed | 11 | (읽기전용) | modal-address |
| 취소(선정후) | list-cancel-selected | 9 | 상세보기 | drawer-influencer |
| 취소(인플) | list-cancel-influencer | 7 | (없음) | — |
| 미선정 | list-unselected | 8 | 상세보기 | drawer-influencer |

액션 흐름: 신청(선정) → 선정(배송입력) → 검수(검수/수정요청) → 수정(재검수) → 완료(읽기전용)

## 3. 일정 (캠페인관리 그룹)
- **dashboard** — KPI 4종(활성캠페인/신규지원자/완료리뷰/이번달매출) + 최근활동 + 오늘일정 + SNS채널별. 읽기전용
- **campaign-calendar** — 월간 캘린더, 날짜클릭→day-drawer(9컬럼 당일일정), 유형칩 필터
- **campaign-schedule-list** — 14컬럼 일정 테이블, 보내기(modal-message)/상세(drawer-influencer)

## 4. 인플루언서 (탐색 그룹 3화면)
**17컬럼 테이블 + 카드 듀얼뷰** + 강력한 필터 공유:
- 필터: 국적(일/한/중/러) · 플랫폼(인스타/유튜브/틱톡/샤오홍슈/페북/X) · 팔로워(5구간) · 성별 · 방문예정일
- 행 3-액션: 상세보기(drawer-influencer) · 저장/삭제 · 제안하기(modal-propose) + bulk-bar(일괄)
- influencer-search(저장) / visit-planned(방문예정 뷰) / saved-influencer(삭제 컬럼)

## 5. 게시판·요금표·계정
- **notice** — 게시판 테이블(분류/제목/등록일/조회수), 조회전용
- **요금표 6종** (전부 조회전용, 수정버튼 없음):
  | 파일 | 정체 | 구조 |
  |---|---|---|
  | pricing | 제품형/방문형 | 8개국 × 팔로워 4구간 단가 |
  | pricing-korea | 한국방문형 | 동일 구조(값 동일) |
  | pricing-it | IT/식품 | 동일 구조 |
  | pricing-superpass | 슈퍼패스 | 11개국 정액 지원금(구간 없음) |
  | pricing-translation | 통역 | 건당/시간당 단가 1행 |
  | pricing-account | **계정·댓글 관리** | ※계정설정 아님 → SNS계정 운영대행 부가서비스 단가표(계정관리 80만/월·댓글 60만/월·공동게재 10만/건) |
- **balance-history** — 국가별 차감현황, 14컬럼 거래내역, 충전회차 필터. 조회전용

## 6. 모달/드로어 생태계 (components.js 동적 주입)
drawer-influencer · drawer-balance · drawer-memo · modal-address · modal-shipping · modal-review · modal-revision · modal-propose · modal-message · modal-confirm · chatbot(AI봇)

## 7. 앱 변환 관점 — 점검 필요 항목
1. **검수(17컬럼) 정보가 앱 inspection-detail에 다 들어갔나** — 정보 무손실 확인
2. **인플루언서 필터(국적/플랫폼/팔로워/성별/방문일)** — 앱에서 누락됨(기확인). 필터 시트 필요
3. **단계별 모달 액션**(배송입력/검수/수정요청/제안) — 앱 동선에 다 반영됐나
4. **앱에 없는 어드민 기능**: 포인트계산기·관리메모·⌘K검색·상시잔액
5. **pricing-account 명칭** — "계정"이라 오해 소지. 앱/어드민에서 라벨 재고
